# バックエンド学習用リポジトリ

## 概要

ReactとViteで作成したTodoアプリを題材に、HonoとSQLiteを使ったバックエンドの基礎を学ぶためのリポジトリです。フロントエンドからAPIを呼び出してTodoを追加・更新する流れや、HTTPメソッド、SQLの書き方を確認しながら、SQLインジェクションの仕組みとORMを使った対策について段階的に学習できます。

## 環境構築

### 必要な環境

- Node.js
- npm

### 依存関係のインストール

プロジェクトのルートディレクトリで、フロントエンドとバックエンドの依存関係をそれぞれインストールする。

```bash
cd frontend
npm install

cd ../backend
npm install
```

### アプリの起動

ターミナルを2つ用意し、それぞれで開発サーバーを起動する。

バックエンド:

```bash
cd backend
npm run dev
```

フロントエンド:

```bash
cd frontend
npm run dev
```

起動後、ブラウザで [http://localhost:5173](http://localhost:5173) を開く。

## 学習方法

### フロントエンドの理解

`frontend/src/App.tsx`を見て、フロントエンドで何をやっているのかざっくり理解する。
特にAPIを呼び出しているところを見ておく。

### バックエンドの理解

`backend/src/index.ts`を見て、エンドポイントの作り方、SQLの書き方をざっくり理解する。
先に以下のリストを予習しておくといいかもしれない。
予習リスト

- HTTPメソッド
- パスパラメータ、クエリパラメータ、リクエストボディ
- SQLの文法

### SQLインジェクションを実行する

1. アプリの画面を操作してデータを追加する
2. `a'); DELETE FROM todos; --` を入力欄に入力し、追加ボタンを押す
3. リロードしてデータが削除されていることを確認する
4. 2の`DELETE`の部分を他の任意のSQLに書き換えてSQLインジェクションを試してみる

###　todoの削除機能を追加する

1. `frontend/src/App.tsx`のコメントアウトを解除する
2. フロントエンドの仕様に合わせて`backend/src/index.ts`に`DELETE`のエンドポイントを追加する
3. アプリを操作して削除機能が追加されたことを確認する

### ORMを使ってSQLインジェクション対策をする

PrismaやDrizzleを使ってSQLインジェクションの対策を行う。
